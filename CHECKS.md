# Проверка восстановленного проекта

Проверено 23.11.2026, Python 3.12. Полный bank-full.csv: 45 211 строк. Все метрики ниже действительно вычислены при проверке, а не переписаны из отчёта.

## Выполнено

- Загрузка официального архива UCI и проверка размеров CSV.
- Проверка формата трёх ноутбуков и синтаксиса всех ячеек.
- Последовательное выполнение всех кодовых ячеек ноутбуков 01 и 02 обычным Python с display; запуск через Jupyter-ядро в этой среде недоступен.
- Полный запуск src/run_all.py --skip-search: 5-fold CV для всех шести моделей, обучение на полном train, итоговая оценка test, матрицы ошибок, ROC-кривые, важность признаков и SHAP на 200 строках.
- GridSearchCV проверен на стратифицированной подвыборке 400 строк; полный подбор на всех 36 168 строках не повторялся. Полная CV в основном прогоне выполнена с параметрами из PDF.
- Данные и производные файлы не включены в архив для GitHub. Выводы ноутбуков очищены.

Для деревьев, RF и GB метрики в таблице совпадают с PDF после округления до четырёх знаков. У Voting есть небольшое расхождение: Test F1=0.4586 вместо 0.4589, precision=0.3755 вместо 0.3760. Восстановленный Voting использует равные веса и логистическую регрессию с max_iter=2000. Исходный код и все его настройки отсутствуют, поэтому объяснить расхождение однозначно нельзя.

Матрица Random Forest совпала с отчётом: TN=7273, FP=712, FN=497, TP=561.
