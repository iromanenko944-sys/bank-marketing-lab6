# Лабораторная работа № 6. Bank Marketing — вариант 4

Деревья решений и ансамблевые методы для предсказания оформления срочного депозита.

## Аннотация

Решается задача бинарной классификации клиентов банка по вероятности оформления депозита. Сравниваются три дерева решений, Random Forest, Gradient Boosting и soft Voting. Дисбаланс учитывается весами классов; параметры выбираются по ROC-AUC на пяти фолдах. В исходном отчёте лучшим ансамблем по CV стал Random Forest, Test ROC-AUC составила 0.8029. Этот репозиторий восстановлен по PDF-отчёту: исходный программный файл не предоставлен, поэтому точное совпадение чисел не гарантируется.

## Данные

- Источник: [UCI Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank+marketing).
- DOI: https://doi.org/10.24432/C5K306.
- Используется именно **bank-full.csv**, а не bank-additional-full.csv: 45 211 строк и 17 исходных столбцов.
- 16 исходных признаков; после исключения duration остаётся 15. Цель y: no=0, yes=1.
- Примерно 88.3% отказов и 11.7% оформлений, дисбаланс около 7.5:1.
- Лицензия UCI: CC BY 4.0. Набор не включён в репозиторий согласно требованиям лабораторной.
- Источник: Moro, S., Rita, P., Cortez, P. (2014). Bank Marketing. UCI Machine Learning Repository.

Загрузка: `python src/download_data.py --variant V4`. При проблемах сети скачайте bank.zip со страницы UCI, извлеките bank-full.csv в data/. Нельзя загружать этот CSV в GitHub.

## Обработка данных

Train/test = 80/20, stratify=y, random_state=42: 36 168 и 9 043 строки. EDA проводится на train. duration исключается: он неизвестен до завершения звонка. unknown остаётся категорией; pdays=-1 означает отсутствие прошлых контактов. Числовые пропуски заполняются медианой, категориальные модой; категории кодируются OneHotEncoder(handle_unknown='ignore'). Для деревьев масштабирование не используется; перед логистической регрессией применяется StandardScaler. Все обучаемые преобразования находятся внутри Pipeline. SMOTE не используется.

Деревья, лес и логистическая регрессия используют class_weight='balanced'. Обёртка бустинга вычисляет sample_weight заново внутри каждого fit, включая CV-фолды.

## Деревья решений

Сравниваются глубина 3 с gini, глубина 3 с entropy и глубокое дерево с min_samples_leaf=10. Левая ветвь соответствует условию ≤, правая >. Значения классов и неоднородность учитывают веса. Выигрыш по Джини рассчитывается как критерий родителя минус взвешенные критерии потомков; информационный выигрыш по энтропии определяется аналогично через энтропию. Разрыв Train AUC и CV/Test AUC помогает обнаружить переобучение.

## Ансамбли и параметры

- Random Forest: поиск n_estimators=[80,160], max_depth=[8,None], min_samples_leaf=5.
- Gradient Boosting: поиск n_estimators=[60,120], learning_rate=[0.05,0.1], max_depth=2.
- Soft Voting: RF + GB + LogisticRegression, равные веса.
- StratifiedKFold: 5 фолдов, shuffle=True, random_state=42. Основная метрика выбора — ROC-AUC.
- Режим без поиска: RF=160 деревьев, max_depth=None; GB=120 деревьев, learning_rate=0.1.

Настройки Voting и shuffle CV восстановлены, поскольку исходный код в PDF отсутствует. CV после подбора по тем же фолдам может быть завышена. Test оценивается для заранее выбранных моделей только после настройки; порог 0.5 не подбирается по test. Не запускайте оценку test многократно ради выбора параметров.

## Интерпретация

По отчёту важны balance, age, day, poutcome_success и campaign. Feature importance отражает вклад в снижение неоднородности и может отдавать преимущество признакам с большим числом разбиений. SHAP рассчитывается для 200 строк train с random_state=42 и показывает направление вклада в вероятность класса 1 для Random Forest. Успех прошлой кампании заметен и в EDA, и в объяснениях модели. Эти связи не доказывают причинность.

## Ограничения и развитие

Данные исторические; возможны временные сдвиги и изменение поведения клиентов. Прикладной порог нужно выбирать на отдельной validation-выборке с учётом стоимости лишнего звонка и пропущенного клиента. Для дальнейшей работы полезны временная проверка, калибровка вероятностей, permutation importance и вложенная CV. Исходный PDF содержит неточности: в выводе LightGBM следует заменить на Gradient Boosting; левая ветвь дерева соответствует ≤; формула G-mean содержит произведение полнот, а не сумму.
