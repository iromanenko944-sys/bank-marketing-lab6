# Данные

UCI Bank Marketing: https://archive.ics.uci.edu/dataset/222/bank+marketing
DOI: https://doi.org/10.24432/C5K306
Лицензия источника: CC BY 4.0.

Из корня проекта: `python src/download_data.py --variant V4`.
Альтернатива: скачайте bank.zip с UCI и извлеките bank-full.csv в эту папку.
Требуется полный файл: 45 211 строк, 17 столбцов, разделитель `;`.
Не используйте bank.csv или bank-additional-full.csv.
По требованиям лабораторной сами данные не публикуются в Git.
